# Kravspecifikation – MicroHydros

## Funktionella krav

| ID | Krav | Prioritet | Status |
|---|---|---|---|
| FR-01 | Systemet ska läsa lufttemperatur inne i odlingsmiljön. | Must | TODO |
| FR-02 | Systemet ska läsa lufttemperatur utanför odlingsmiljön. | Must | TODO |
| FR-03 | Systemet ska läsa temperatur i vatten/näringslösning. | Must | TODO |
| FR-04 | Systemet ska läsa relativ luftfuktighet inne i odlingsmiljön. | Must | TODO |
| FR-05 | Systemet ska utföra mätningar återkommande. | Must | TODO |
| FR-06 | Embedded-systemet ska behandla insamlad mätdata. | Must | TODO |
| FR-07 | Mätdata ska kunna skickas till ett externt system. | Must | TODO |
| FR-08 | Systemet ska kunna upptäcka minst vissa felaktiga/orimliga mätvärden. | Must | TODO |

## Projektbeslut som ännu inte är kravsatta

Följande ska beslutas och dokumenteras av gruppen:

- exakt mätintervall,
- val av sensorer,
- exakta rimlighetsgränser för mätvärden,
- slutlig kommunikationslösning,
- format för eventuell långsiktig lagring.
